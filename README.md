## Description

**KMines** is a classic Minesweeper game from the KDE project. The goal is to uncover all squares without detonating any mines. Numbers on revealed squares indicate how many mines are adjacent, helping you deduce safe moves. It features multiple difficulty levels, custom board sizes, and a high-score table.

---

## About This Package

This is an **Aurelis Linux** package built as an AppImage. It bundles all dependencies and runs on any Linux distribution (including older and musl-based systems) without requiring FUSE, thanks to [uruntime](https://github.com/VHSgunzo/uruntime).

While designed for Aurelis Linux, this AppImage works as a regular portable application on any Linux distribution.
